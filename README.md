# Higea - PC Manager

🛡️ **Open Source Windows Optimization Tool**

**Higea** is a lightweight, open-source all-in-one desktop utility built on **.NET (WPF)**, designed to keep your Windows environment clean, organized, and optimized for peak performance. Featuring a sleek, modern dark user interface, Higea streamlines system maintenance with just a few clicks.

---

## ✨ Key Features

### 📁 File Organizer
* **Smart Sorting:** Automatically scan and sort disorganized files by type (documents, images, executables, etc.) into their proper destination folders.
* **Flexible Action:** Choose a specific target folder using the file browser or perform a massive cleanup using the "Organize Entire PC" feature.
* **Real-time Metrics:** Track exactly how many files were moved or skipped during the process via dynamic UI counters.

### 🧹 System Cleaner
* **Temp Files Removal:** Instantly clear accumulated junk files from Windows system directories (`%TEMP%` and `C:\Windows\Temp`) to free up disk space.
* **Recycle Bin Janitor:** Empty the system Recycle Bin directly from the application interface without going back to the desktop.

### 🎮 Gaming Optimizer
* **Cache Purge:** Wipe NVIDIA shader caches (DirectX, OpenGL, OptiX) to eliminate micro-stuttering and smooth out framerates.
* **Memory Management:** Flush Windows Prefetch and release RAM (Working Set) to reduce OS overhead before launching a game.
* **Network & Power Tweaks:** Flush the DNS cache for optimal connectivity and quickly toggle the **High Performance** power plan to maximize hardware utilization.

---

## 🛠️ Built With

* **Framework:** .NET (C#)
* **UI Framework:** WPF (Windows Presentation Foundation)

---

## 🚀 Installation & Usage

1. Head over to the **Releases** section of this repository.
2. Download the executable file from the latest release.
3. Run `Higea.exe` (Running as Administrator is highly recommended so the utility has the proper permissions to clear system directories and apply power plans).
